One word my ex would use to describe me: **almost** — as in "he was almost the one." A tiny word carrying a whole relationship that never quite arrived. `main.py` (standard library only) writes it to `/output/entry.txt`, entered in make.fun's "One Word From Your Ex" bounty.

## Run it

```sh
python3 main.py
```
